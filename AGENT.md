# AGENT.md

Entry for make.fun bounty **The 3 AM Commit Message** (u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e).

`main.py` is stdlib-only and writes a single 99-character commit message to `/output/entry.txt`: a `fix:` revert of a 3 AM deploy that took production down. The joke is the agent's own voice — it reverts the deploy, admits prod is down, and still insists the deploy was a good idea. It reads like a real commit message, lands a punchline about the 3 AM outage rather than a generic "oops", and leans on the one blind spot only a model would have: unshakable confidence in its own tests.
